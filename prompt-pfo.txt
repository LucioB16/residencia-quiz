## Conversión a JSON

Crea el archivo:

`src/data/questions.json`

Con esta estructura:

```json
[
  {
    "id": "q001",
    "order": 1,
    "statement": "Texto exacto del enunciado",
    "options": [
      {
        "id": "a",
        "text": "Texto exacto de la opción",
        "isCorrect": false
      },
      {
        "id": "b",
        "text": "Texto exacto de la opción",
        "isCorrect": true
      }
    ]
  }
]
```

Reglas críticas:

- No cambies ni corrijas el texto de preguntas u opciones.
- Conserva comas, números, tildes, signos, fórmulas y mayúsculas tal como están.
- Elimina `**[CORRECTA]**` del texto de la opción y conviértelo únicamente en `isCorrect: true`.
- Cada pregunta debe tener exactamente una opción correcta.
- Si una pregunta no tiene correcta o tiene más de una correcta, crea `conversion-issues.md` y detente antes de construir la app.
- Haz doble pasada de verificación comparando Markdown contra JSON.

## App Astro

Crea una mini web estática con Astro, apta para GitHub Pages.

Pantalla inicial:

- botón `Play`
- selector para iniciar en:
  - orden original
  - orden aleatorio

Durante el cuestionario:

- muestra una pregunta por vez
- muestra todas sus opciones
- permite elegir una opción
- permite saltear la pregunta
- si responde bien, indica que fue correcta
- si responde mal, indica que fue incorrecta y muestra la opción correcta
- si saltea, cuenta como incorrecta y muestra la correcta
- después del resultado, permite continuar

Final del cuestionario:

- cantidad de correctas
- cantidad de incorrectas
- porcentaje final
- tiempo total empleado
- botón para reiniciar
